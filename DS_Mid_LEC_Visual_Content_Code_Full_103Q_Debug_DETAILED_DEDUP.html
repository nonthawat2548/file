Array — โครงสร้างพื้นฐานที่ใช้ Index

Array เก็บข้อมูลหลายค่าใน object เดียวกัน ข้อมูลทุกช่องมีชนิดเดียวกัน และเข้าถึงด้วย index เริ่มจาก 0 จุดสำคัญคือขนาดของ Array ธรรมดาจะถูกกำหนดตอนสร้างแล้วไม่สามารถเปลี่ยน length ของ object เดิมได้

1.1 ประกาศ vs สร้าง Array

int[] a;              // มีตัวแปร reference แต่ยังไม่มี Array object

a = new int[5];       // สร้าง Array object ขนาด 5

int[] b = {10,20,30}; // สร้างพร้อมค่าเริ่มต้น
อ่านโค้ดให้เป็นภาพ
  • int[] a; ยังไม่มีช่องข้อมูลจริง
  • new int[5] สร้างช่อง 5 ช่อง: index 0,1,2,3,4
  • สมาชิก int ที่ยังไม่กำหนดค่าเริ่มเป็น 0

1.7 Object Array

class Student {
    int id;
    String name;

    Student(int id, String name) {
        this.id = id;
        this.name = name;
    }
}

Student[] s = new Student[3];
// ตอนนี้ s[0], s[1], s[2] ยังเป็น null

s[0] = new Student(101, "A");
s[1] = new Student(102, "B");
🔎 อธิบายโค้ดตัวอย่างนี้
  • new Student[n] สร้าง Array ของ reference จำนวน n ช่อง
  • แต่ละช่องเริ่มเป็น null จนกว่าจะทำ new Student(...)
  • ถ้าเรียก field/method ผ่านช่องที่ยัง null จะเกิด NullPointerException
ภาพที่ควรนึก: Object Array ต้องแยกคำว่า สร้าง Array กับ สร้าง Object แต่ละตัว ออกจากกัน
จุดหลอก: new Student[3] สร้าง Array ของ reference ไม่ได้สร้าง Student 3 object

8) Array ส่งเข้า Method: Java ยังเป็น Pass-by-Value

static void change(int[] a){
    a[0] = 50;            // แก้ Array object เดิมได้
    a = new int[]{7,8};   // เปลี่ยนแค่ local reference a
}

int[] x = {1,2,3};
change(x);

// x = [50,2,3]
🔎 อธิบายโค้ดตัวอย่างนี้
  • คำสั่ง new int[n] คือจุดที่สร้าง Array object จริง
  • สมาชิก int เริ่มต้นเป็น 0 และ index ถูกต้องคือ 0 ถึง n-1
  • ตัวแปร Array เก็บ reference ที่ชี้ไปยัง object นั้น
ภาพที่ควรนึก: อย่าสับสนระหว่าง จำนวนช่อง (length) กับ index สุดท้าย (length-1)

ค่าที่ถูกส่งเข้า method คือ “ค่าของ reference” ดังนั้น parameter ภายใน method ยังชี้ object เดิมได้ แต่การ assign parameter ให้ชี้ object ใหม่ ไม่ได้เปลี่ยนตัวแปร reference ของผู้เรียก

public static int[] addFirst(int[] source, int x) {
    int[] temp = new int[source.length + 1];
    temp[0] = x;

    for (int i = 0; i < source.length; i++) {
        temp[i + 1] = source[i];
    }

    return temp;
}
  1. สร้าง temp ใหญ่กว่าเดิม 1
  2. ข้อมูลใหม่อยู่ temp[0]
  3. source[i] ถูกย้ายไป temp[i+1]
  4. return reference ของ Array ใหม่
int[] x = {1,2,3,4,5};
x = addFirst(x, 0);
// x = [0,1,2,3,4,5]
🔎 อธิบายโค้ดตัวอย่างนี้
  • สร้าง temp ยาวกว่าเดิม 1 ช่อง เพราะ Array เดิมขยายไม่ได้
  • ใส่ค่าใหม่ที่ temp[0]
  • สมาชิกเดิมถูกย้ายไป temp[i+1] จึงเลื่อนไปขวา 1 ช่อง
  • ต้อง return temp เพื่อให้ผู้เรียกได้รับ reference ของ Array ใหม่
ภาพที่ควรนึก: ภาพในหัว: สร้างใหม่ → ใส่ค่าใหม่ → copy ของเดิม → return
Logical Error ที่อาจออก: ถ้าเขียนเมธอด void แล้วจบด้วย source = temp; ข้อมูลใน x ของ main จะยังไม่เปลี่ยน เพราะ source เป็น local parameter

2.2 addLast()

public static int[] addLast(int[] source, int x) {
    int[] temp = new int[source.length + 1];

    for (int i = 0; i < source.length; i++) {
        temp[i] = source[i];
    }

    temp[temp.length - 1] = x;
    return temp;
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • สร้าง temp ยาวกว่าเดิม 1 ช่อง
  • copy สมาชิกเดิมไปตำแหน่งเดิม ไม่ต้องเลื่อน
  • ใส่ x ที่ temp[temp.length-1]
  • คืน temp กลับไปให้ตัวแปรหลักรับ reference ใหม่
ภาพที่ควรนึก: addLast ง่ายกว่า addFirst เพราะข้อมูลเดิมไม่ต้องเลื่อนตำแหน่ง
สไลด์ Week 3 หน้าตัวอย่างโค้ด addLast มีบรรทัด temp[0] = x ซึ่งขัดกับ algorithm บนสไลด์ที่บอกให้ใส่ข้อมูลใหม่ “ช่องสุดท้าย” เว็บนี้จึงแสดงเวอร์ชันที่สอดคล้องกับ algorithm เพื่อใช้ทำความเข้าใจ และแยกเรื่องนี้ไว้ชัดเจน

public static int[] insert(int[] source, int x, int index) {
    int[] temp = new int[source.length + 1];

    for (int i = 0; i < index; i++)
        temp[i] = source[i];

    temp[index] = x;

    for (int i = index; i < source.length; i++)
        temp[i + 1] = source[i];

    return temp;
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • ส่วนก่อน index ที่จะแทรก copy อยู่ตำแหน่งเดิม
  • เขียนข้อมูลใหม่ลง temp[index]
  • สมาชิกเดิมตั้งแต่ index เป็นต้นไปต้องย้ายไป temp[i+1]
ภาพที่ควรนึก: จุดที่ข้อสอบชอบหลอกคือ loop ด้านขวา ถ้าลืม +1 ข้อมูลใหม่จะถูกทับ
Insert กลาง = ก่อน index อยู่ที่เดิม • ช่อง index เป็นข้อมูลใหม่ • ตั้งแต่ index ของเดิมเลื่อนไปขวา 1

2.4 replace()

public static void replace(int[] source, int x, int key) {
    for (int i = 0; i < source.length; i++) {
        if (source[i] == key) {
            source[i] = x;
            break;
        }
    }
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • replace ไม่ได้เปลี่ยนจำนวนสมาชิก
  • ถ้ารู้ index ที่ถูกต้องสามารถแก้ a[index] ได้โดยตรง
  • ควรตรวจว่า index อยู่ในช่วง 0..length-1 ก่อน
ภาพที่ควรนึก: ต่างจาก add/delete ตรงที่ไม่จำเป็นต้องสร้าง Array ใหม่เพียงเพื่อเปลี่ยนค่า

replace ไม่เปลี่ยนจำนวนช่อง จึงไม่จำเป็นต้องสร้าง Array ใหม่ในกรณีนี้

2.5 deleteFirst()

public static int[] deleteFirst(int[] source) {
    int[] temp = new int[source.length - 1];
    for (int i = 1; i < source.length; i++)
        temp[i - 1] = source[i];
    return temp;
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • Array ใหม่สั้นกว่าเดิม 1 ช่อง
  • สมาชิกที่ไม่ถูกลบต้องถูก copy ไปยัง Array ใหม่
  • ถ้าลบกลาง สมาชิกด้านขวาของตำแหน่งลบต้องเลื่อนไปซ้าย 1 ช่อง
ภาพที่ควรนึก: ตรวจขอบเขต loop ให้สัมพันธ์กับ temp.length เพราะ temp สั้นกว่า source

2.7 delete(index)

public static int[] delete(int[] source, int index) {
    int[] temp = new int[source.length - 1];

    for (int i = 0; i < index; i++)
        temp[i] = source[i];

    for (int i = index + 1; i < source.length; i++)
        temp[i - 1] = source[i];

    return temp;
}
🔎 จุดเฉพาะของตัวอย่างนี้ — 2.7 delete(index)

void addFirst(Node n) {
    if (head == null) {
        head = tail = n;
    } else {

3.4 addLast()

void addLast(Node n) {
    if (head == null) {
        head = tail = n;
    } else {
        tail.next = n;
        tail = n;
    }
    count++;
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • ถ้าลิสต์ว่าง Node ใหม่เป็นทั้ง head และ tail
  • ถ้าไม่ว่าง tail.next = n ต่อ Node ใหม่ไว้ด้านท้าย
  • จากนั้นเลื่อน tail = n
ภาพที่ควรนึก: มี tail ทำให้เพิ่มท้ายได้โดยไม่ต้องเดินหาท้ายใหม่

เพราะมี tail จึงเข้าถึงโหนดสุดท้ายตรง ๆ และเพิ่มท้ายได้โดยไม่ traversal ทั้งลิสต์

3.5 Traversal

Node p = head;
while (p != null) {
    System.out.println(p.data);
    p = p.next;
}
ไล่โค้ด Traversal ทีละบรรทัด:
  1. Node p = head; — สร้างตัวแปร p ให้เริ่มชี้ Node แรก แต่ ไม่ได้ย้าย head
  2. while (p != null) — ถ้า p ยังชี้ Node อยู่ ให้ทำงานใน loop
  3. System.out.println(p.data) — อ่านข้อมูลของ Node ที่ p กำลังชี้
  4. p = p.next; — ให้ p เดินไป Node ถัดไป
  5. เมื่อ Node สุดท้ายมี next == null → p กลายเป็น null → loop จบ
🔎 อธิบายโค้ดตัวอย่างนี้
  • p = head ให้ตัวแปรชั่วคราวเริ่มที่ Node แรก
  • while(p != null) ทำงานตราบใดที่ยังมี Node ให้เยี่ยมชม
  • p = p.next ย้าย p ไป Node ถัดไป
ภาพที่ควรนึก: Traversal ไม่ได้ย้าย head; เราใช้ p เพื่อเดินโดยไม่ทำลายตำแหน่งหัวลิสต์
p = p.next; คือคำสั่งที่ทำให้ตัวแปร p เดินจาก Node ปัจจุบันไป Node ถัดไป

Node search(int id) {
    Node p = head;
    while (p != null) {
        if (p.data.id == id)
            return p;
        p = p.next;

    return null;
}

3.7 Insert หลัง Node p

void insertAfter(Node p, Node n) {
    n.next = p.next;
    p.next = n;

    if (tail == p)
        tail = n;

    count++;
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • n.next = p.next ให้ N จำ Node ทางขวาเดิมก่อน
  • p.next = n จึงค่อยเชื่อม p มาหา N
  • ถ้า p เป็น tail ต้องอัปเดต tail เป็น n
ภาพที่ควรนึก: หลักคือ เก็บลิงก์เก่าก่อนเขียนทับ
ลำดับคำสั่งสำคัญ: ต้องให้ n จำโหนดเดิมทางขวาก่อน ถ้าเขียน p.next=n แล้วค่อย n.next=p.next จะเกิด n.next=n

3.8 Delete หลัง p

void deleteAfter(Node p) {
    if (p == null || p.next == null) return;

    Node target = p.next;
    p.next = target.next;

    if (target == tail)
        tail = p;

4.1 Array-based Stack แบบเขียนเอง

class MyStack {
    int[] data;
    int top;

    MyStack(int size) {
        data = new int[size];
        top = -1;
    }

    boolean isEmpty() {
        return top == -1;
    }

    boolean isFull() {
        return top == data.length - 1;
    }

    boolean push(int x) {
        if (isFull()) return false;
        top++;
        data[top] = x;
        return true;
    }

    Integer pop() {
        if (isEmpty()) return null;
        int x = data[top];
        top--;
        return x;
    }

    Integer peek() {
        if (isEmpty()) return null;
        return data[top];
    }
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • top=-1 หมายถึง Stack ว่าง
  • push: ตรวจ full → เพิ่ม top → เขียนค่าที่ data[top]
  • pop: ตรวจ empty → อ่าน data[top] → ลด top
  • peek: อ่าน top โดยไม่ลด top
ภาพที่ควรนึก: Stack แบบ Array ใช้ top เป็น index ของสมาชิกบนสุด
Error pattern: ถ้า top เริ่ม -1 แต่เขียน data[top]=x; top++; จะพยายามใช้ data[-1] ก่อน

            return false;

        top++;
        data[top] = x;
        return true;
    }

    int pop(){
        if(isEmpty())
            throw new RuntimeException("Stack empty");

        int x = data[top];
        top--;
        return x;
    }

    int peek(){
        if(isEmpty())
            throw new RuntimeException("Stack empty");

        return data[top];
    }
}
ทำไม top เริ่ม -1? เพราะยังไม่มีสมาชิก ช่องแรกคือ index 0 ดังนั้นตอน push ครั้งแรกจึง top++ กลายเป็น 0 แล้วค่อยเขียน data[0]

4) Linked-list-based Stack

class StackNode {
    int data;
    StackNode next;
}

class MyLinkedStack {
    StackNode top;

    void push(int x){
        StackNode n = new StackNode();
        n.data = x;

        n.next = top;
        top = n;
    }

    int pop(){
        if(top == null)
            throw new RuntimeException("empty");

        int x = top.data;
        top = top.next;
        return x;
    }
}

8.1 Bubble Sort

เทียบตัวติดกัน ถ้าซ้ายมากกว่าขวา swap กัน หลังหนึ่ง pass ค่ามากสุดของช่วงจะไปอยู่ท้าย

static void bubbleSort(int[] a) {
    for (int end = a.length - 1; end > 0; end--) {
        boolean swapped = false;

        for (int j = 0; j < end; j++) {
            if (a[j] > a[j + 1]) {
                int temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
                swapped = true;
            }
        }

        if (!swapped) break;
    }
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • loop นอกลดขอบเขตท้าย เพราะท้ายที่ sorted แล้วไม่ต้องตรวจซ้ำ
  • loop ในเปรียบเทียบสมาชิกติดกัน a[j] กับ a[j+1]
  • ถ้าซ้ายมากกว่าขวาให้ swap
  • ตัวแปร swapped ใช้หยุดเร็วเมื่อไม่มีการสลับเลย
ภาพที่ควรนึก: จบหนึ่ง pass ค่ามากสุดของช่วงที่ยังไม่ sorted จะไปอยู่ท้าย
Error trap: ถ้า loop ในเขียน j <= end จะอ่าน a[j+1] เกินช่วงตอน j=end

8.2 Selection Sort

ในแต่ละรอบหา index ของค่าต่ำสุดจากส่วนที่ยังไม่ sorted แล้ว swap มาที่ i

static void selectionSort(int[] a) {
    for (int i = 0; i < a.length - 1; i++) {
        int minIndex = i;

        for (int j = i + 1; j < a.length; j++) {
            if (a[j] < a[minIndex])
                minIndex = j;
        }

        int temp = a[i];
        a[i] = a[minIndex];
        a[minIndex] = temp;
    }
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • ตำแหน่ง i คือจุดที่กำลังจะวางค่าที่ถูกต้อง
  • ตั้ง minIndex=i แล้วสแกนส่วนที่เหลือเพื่อหา minimum
  • หลังหา min จบจึง swap แค่ครั้งเดียวต่อ pass
ภาพที่ควรนึก: อย่าเอา swap ไปไว้ใน loop ค้นหา min
Logical trap: minIndex ต้องเริ่มที่ i ของ pass ปัจจุบัน ไม่ใช่ 0 ทุกครั้ง

8.3 Shell Sort

ทำ gapped insertion sort โดยเริ่ม gap ใหญ่ แล้วลดลงจน gap=1

static void shellSort(int[] a) {
    for (int gap = a.length / 2; gap > 0; gap /= 2) {
        for (int i = gap; i < a.length; i++) {
            int temp = a[i];
            int j = i;

            while (j >= gap && a[j - gap] > temp) {
                a[j] = a[j - gap];
                j -= gap;
            }

            a[j] = temp;
        }
    }
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • เริ่มด้วย gap ขนาดใหญ่เพื่อย้ายค่าที่อยู่ไกลกัน
  • แต่ละรอบทำ gapped insertion sort
  • ลด gap จนสุดท้าย gap=1
ภาพที่ควรนึก: ถ้า trace มี gap เช่น 4→2→1 ให้นึกถึง Shell Sort
Shell = จำคำว่า GAP ถ้า trace มี gap 4 → 2 → 1 ให้คิด Shell ก่อน

8.4 Radix Sort (LSD)

จัดตาม digit จากหลักหน่วย → สิบ → ร้อย โดยใช้ stable counting/bucket ในแต่ละหลัก

static void radixSort(int[] a) {
    int max = a[0];
    for (int x : a)
        if (x > max) max = x;

    for (int exp = 1; max / exp > 0; exp *= 10)
        countingByDigit(a, exp);
}

static void countingByDigit(int[] a, int exp) {
    int[] output = new int[a.length];
    int[] count = new int[10];

    for (int x : a)
        count[(x / exp) % 10]++;

    for (int i = 1; i < 10; i++)
        count[i] += count[i - 1];

    for (int i = a.length - 1; i >= 0; i--) {
        int digit = (a[i] / exp) % 10;
        output[count[digit] - 1] = a[i];
        count[digit]--;
    }

    for (int i = 0; i < a.length; i++)
        a[i] = output[i];
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • หา digit ปัจจุบันด้วย (x/exp)%10
  • นับจำนวนสมาชิกในแต่ละ digit 0..9
  • สร้าง output แบบ stable เพื่อไม่ทำลายลำดับจากหลักก่อนหน้า
  • ทำซ้ำ exp=1,10,100,...
ภาพที่ควรนึก: Radix ไม่ใช้การ compare คู่ค่าเป็นแกนหลัก แต่แจกข้อมูลตามหลัก

8.5 Merge Sort

แบ่งช่วงครึ่งซ้ำ ๆ จนเหลือ 1 ตัว แล้ว merge สองช่วงที่ sorted กลับเข้าด้วยกัน

static void mergeSort(int[] a, int left, int right) {
    if (left >= right) return;

    int mid = (left + right) / 2;
    mergeSort(a, left, mid);
    mergeSort(a, mid + 1, right);
    merge(a, left, mid, right);
}

static void merge(int[] a, int left, int mid, int right) {
    int[] temp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;

    while (i <= mid && j <= right) {
        if (a[i] <= a[j]) temp[k++] = a[i++];
        else              temp[k++] = a[j++];
    }

    while (i <= mid) temp[k++] = a[i++];
    while (j <= right) temp[k++] = a[j++];

    for (int t = 0; t < temp.length; t++)
        a[left + t] = temp[t];
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • base case หยุดเมื่อช่วงมี 0 หรือ 1 ตัว
  • แบ่งช่วงเป็น left..mid และ mid+1..right
  • recursive เรียงสองฝั่งก่อน แล้วค่อย merge
ภาพที่ควรนึก: ถ้า recursive ฝั่งขวาเริ่มที่ mid แทน mid+1 อาจทำให้ช่วงไม่ลด
Recursion trap: base case ต้องหยุดเมื่อ left >= right เพราะช่วง 1 ตัวเรียงอยู่แล้ว

8.6 Quick Sort

เลือก pivot, partition ให้ค่าที่ควรอยู่ซ้าย/ขวา แล้ว recursive สองฝั่ง

static void quickSort(int[] a, int low, int high) {
    if (low < high) {
        int p = partition(a, low, high);
        quickSort(a, low, p - 1);
        quickSort(a, p + 1, high);
    }
}

static int partition(int[] a, int low, int high) {
    int pivot = a[high];
    int i = low - 1;

    for (int j = low; j < high; j++) {
        if (a[j] <= pivot) {
            i++;
            int temp = a[i];
            a[i] = a[j];
            a[j] = temp;
        }
    }

    int temp = a[i + 1];
    a[i + 1] = a[high];
    a[high] = temp;

    return i + 1;
}
🔎 อธิบายโค้ดตัวอย่างนี้
  • partition คืน index ของ pivot หลังจัดตำแหน่ง
  • pivot ตำแหน่งนั้นถูกแล้ว จึง recursive เฉพาะซ้าย p-1 และขวา p+1
  • base case คือ low ไม่ต่ำกว่า high
ภาพที่ควรนึก: อย่าเอา pivot เข้า recursive ซ้ำ
Partition trap: ถ้า pivot อยู่ a[high] loop scan ปกติจะถึง j < high แล้วค่อยย้าย pivot หลัง scan
